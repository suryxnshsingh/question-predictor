# Adding New Subjects to the Question Predictor

This guide explains how to add Chemistry, Mathematics, Biology, or any other subject to the prediction service.

## Overview

The system is designed to be modular. Each subject requires:
1. **Raw data file** - CSV with questions from that subject
2. **Topic keywords config** - Subject-specific topic extraction rules
3. **Processed data** - Generated by running the pipeline

## Step-by-Step Guide

### Step 1: Prepare Raw Data

Place your subject data in `data/raw/` following the naming convention:

```
data/raw/{subject}_train_{start_year}_{end_year}.csv
data/raw/{subject}_holdout_{year}.csv
```

**Example:**
```
data/raw/chemistry_train_2016_2024.csv
data/raw/chemistry_holdout_2025.csv
```

**Required columns:**
| Column | Description | Example |
|--------|-------------|---------|
| `Subject` | Subject name | "Chemistry" |
| `Chapter_Name` | Chapter name | "Organic Chemistry" |
| `Question` | Question text (can include HTML) | "<p>Q. What is...</p>" |
| `Question type` | Type of question | "Short Answer" |
| `Marks` | Marks for question | 3 |
| `Year` | Year of exam | 2023 |

**Filter from main dataset:**
```python
import pandas as pd

# Load full dataset
df = pd.read_csv('path/to/full_questions.csv')

# Filter for Chemistry
chemistry_df = df[df['Subject'] == 'Chemistry']

# Split into train (2016-2024) and holdout (2025)
train = chemistry_df[chemistry_df['Year'] <= 2024]
holdout = chemistry_df[chemistry_df['Year'] == 2025]

# Save
train.to_csv('data/raw/chemistry_train_2016_2024.csv', index=False)
holdout.to_csv('data/raw/chemistry_holdout_2025.csv', index=False)
```

### Step 2: Create Topic Keywords Configuration

Create a new config file in `config/topics/`:

```
config/topics/{subject}_topics.py
```

**Example: `config/topics/chemistry_topics.py`**

```python
"""
Chemistry topic keywords for extraction
"""

CHEMISTRY_TOPICS = {
    # Organic Chemistry
    'Hydrocarbons': ['hydrocarbon', 'alkane', 'alkene', 'alkyne', 'aromatic'],
    'Alcohols Phenols': ['alcohol', 'phenol', 'ether'],
    'Aldehydes Ketones': ['aldehyde', 'ketone', 'carbonyl'],
    'Carboxylic Acids': ['carboxylic', 'acid', 'ester'],
    'Amines': ['amine', 'amino', 'nitro'],
    'Polymers': ['polymer', 'polymerization', 'plastic'],

    # Inorganic Chemistry
    'Coordination Compounds': ['coordination', 'ligand', 'complex'],
    'D Block Elements': ['transition', 'd block', 'd-block'],
    'F Block Elements': ['lanthanide', 'actinide', 'f block'],
    'Metallurgy': ['metallurgy', 'extraction', 'ore'],

    # Physical Chemistry
    'Solutions': ['solution', 'colligative', 'osmotic'],
    'Electrochemistry': ['electrochemical', 'galvanic', 'electrolysis'],
    'Chemical Kinetics': ['kinetics', 'rate', 'order of reaction'],
    'Surface Chemistry': ['adsorption', 'colloid', 'catalyst'],
    'Thermodynamics': ['enthalpy', 'entropy', 'gibbs'],

    # Add more topics as needed...
}

# Question pattern keywords (same across subjects)
DERIVATION_KEYWORDS = ['derive', 'establish', 'prove', 'deduce']
DEFINITION_KEYWORDS = ['define', 'what is', 'what are', 'explain']
NUMERICAL_KEYWORDS = ['calculate', 'find', 'determine', 'compute']
```

**Tips for creating topic keywords:**
1. Look at your chapter names first
2. Review 10-20 sample questions per chapter
3. Identify recurring keywords/concepts
4. Group related concepts under one topic
5. Include variations (e.g., "p-n junction", "pn junction", "diode")

### Step 3: Register Subject in Configuration

Edit `config/subjects.py`:

```python
"""
Subject configuration registry
"""

SUBJECTS = {
    'physics': {
        'name': 'Physics',
        'train_data': 'data/raw/physics_train_2016_2024.csv',
        'holdout_data': 'data/raw/physics_holdout_2025.csv',
        'topics_config': 'config.topics.physics_topics',
        'topics_var': 'PHYSICS_TOPICS'
    },
    'chemistry': {
        'name': 'Chemistry',
        'train_data': 'data/raw/chemistry_train_2016_2024.csv',
        'holdout_data': 'data/raw/chemistry_holdout_2025.csv',
        'topics_config': 'config.topics.chemistry_topics',
        'topics_var': 'CHEMISTRY_TOPICS'
    },
    # Add more subjects here...
}
```

### Step 4: Run the Pipeline

```bash
# Activate virtual environment
source venv/bin/activate

# Process the new subject
python scripts/process_subject.py --subject chemistry

# This will:
# 1. Load raw data
# 2. Extract topics using your config
# 3. Save processed data to data/processed/chemistry_with_topics.csv
# 4. Generate predictions
# 5. Export RAG data to data/output/chemistry_predictions.json
```

### Step 5: Validate Results

## Common Issues & Solutions

### Issue 1: Low topic extraction rate
**Symptom:** Many questions get chapter name as topic instead of specific topic
**Solution:** Add more keywords to your topic config. Review questions that aren't matching.

```python
# Debug: Find questions not matching any topic
df = pd.read_csv('data/processed/chemistry_with_topics.csv')
unmatched = df[df['primary_topic'] == df['Chapter_Name']]
print(unmatched['Question'].head(10))
# Look for common keywords to add
```

### Issue 2: Too many topics / low frequency
**Symptom:** 100+ topics, most appearing only 1-2 times
**Solution:** Merge related topics. Broader topics are more predictable.

```python
# Before: Too granular
'Alkanes': ['alkane'],
'Alkenes': ['alkene'],
'Alkynes': ['alkyne'],

# After: Better grouping
'Hydrocarbons': ['alkane', 'alkene', 'alkyne', 'hydrocarbon'],
```

### Issue 3: Overlapping keywords
**Symptom:** Same question matching multiple topics
**Solution:** Make keywords more specific or prioritize.

```python
# Problem: "electric field" matches both
'Electric Field': ['electric field'],
'Electromagnetic Field': ['electric field', 'magnetic field'],

# Solution: Make specific
'Electromagnetic Field': ['electromagnetic field', 'em field'],
```

## Checklist for Adding New Subject

- [ ] Raw data CSV with required columns
- [ ] Train/holdout split (e.g., 2016-2024 train, 2025 holdout)
- [ ] Topic keywords config file created
- [ ] Subject registered in `config/subjects.py`
- [ ] Pipeline run successfully
- [ ] Validation metrics acceptable (target: >70% F1)
- [ ] RAG export generated

## Estimated Effort

| Task | Time |
|------|------|
| Prepare raw data | 30 min |
| Create topic keywords | 2-4 hours (depends on subject complexity) |
| Run pipeline | 5 min |
| Validate & tune keywords | 1-2 hours |
| **Total** | **4-7 hours per subject** |

The main effort is in creating good topic keywords. Physics took ~50 keywords across 15 chapters. Chemistry might need 60-80 keywords due to more diverse topics.
